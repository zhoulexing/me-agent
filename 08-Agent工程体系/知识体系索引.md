## 使用规则

- 一个课题只能有一个主文档。
- 关联领域的 README 通过链接指向主文档。
- 如果跨领域问题已经大到拥有独立问题、案例和验证方法，再拆成新的课题。
- 书稿和课程只重新组织阅读顺序，不复制知识源正文。
