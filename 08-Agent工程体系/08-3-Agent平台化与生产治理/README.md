# Agent 平台化与生产治理

## 核心问题

> 一个能完成任务的 Agent，如何成为可接入、可交付、可观测、可治理并能长期稳定运行的生产服务？

## 深度课题

1. **Host、Runtime 和 Control Plane 应该如何划分**：明确接入、执行、配置与资源管理的依赖方向和故障边界。
2. **Agent 事件协议应该如何设计才能支持不同客户端**：区分 Streaming、Tool、Approval、Verification、Final 和 Done 事件。
3. **如何保证消息和 Artifact 可靠交付**：处理发送成功但记录失败、重复发送、路由恢复、Channel 降级和安全检查。
4. **Agent 系统的可观测性应该观察什么**：从模型、工具、Session、Goal、Outcome、Recovery 和用户介入建立语义观测。
5. **如何区分模型错误、Harness 错误、工具错误和业务失败**：建立可操作的错误分类和重试边界。
6. **概率系统应该如何定义 SLI 和 SLO**：使用目标成功率、未知率、恢复率、偏离率、用户介入、成本和延迟。
7. **如何关联一次任务中的完整调用链**：统一 User、Session、Run、Model、Tool、Verifier、Delivery 和 Background Job。
8. **如何管理 Agent 配置和版本**：处理动态更新、Session 兼容、配置漂移、灰度和回滚。
9. **多用户和多租户情况下如何保证隔离**：覆盖身份、Session、Workspace、Memory、凭证、工具和观测数据。
10. **如何控制 Agent 的成本、延迟和资源**：权衡模型、Context、Tool、Subagent、并发、队列和降级策略。
11. **如何进行 Agent 灰度、发布和回滚**：关联模型、Prompt、Harness、Skill 版本与已经开始的任务。
12. **如何从生产 Trace 重建真实问题**：研究事件、环境、外部依赖、隐私、复现和回归案例提取。

## 面试级判断标准

优秀回答需要从单任务扩大到多用户、多实例和多版本，说明协议、资源、隔离、观测和发布之间如何共同保证生产可靠性。

## 建设顺序

先研究三层边界、事件协议和可观测语义，再进入多租户、资源治理和发布。每个课题应包含生产故障案例、Trace 或架构伪代码。
