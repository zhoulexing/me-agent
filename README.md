# me-agent

周乐杏的个人资料、内容创作、信息记录与 Agent 工程研究工作区。

## 当前目录

| 目录 | 用途 |
| --- | --- |
| `01-基本信息/` | 稳定的个人信息 |
| `02-内容创作/` | 个人与技术表达的稿件，文件直接平铺 |
| `03-信息记录/` | 按日期记录各种信息；`索引.md` 用于检索 |
| `05-主题资料/` | 按主题维护的清单、模板、备忘和长期资料 |
| `05-主题资料/Agent工程/` | 逐步沉淀 Agent 工程课题 |
| `07-人物研究/` | 按人物组织的研究资料 |
| `projects/` | 独立的项目与源码仓库 |
| `cmd/` | `zlx-cli` 命令入口、授权、平台对接与业务操作 |
| `skills/` | 本工作区维护的 Agent Skills |
| `outputs/`、`docs/` | 生成结果与辅助文档 |

`01-基本信息/` 保持原有结构。`02-内容创作/` 汇集原“个人认知”和“技术认知”稿件，不按类型或发布状态建子目录。随手记录、外部链接、想法、事件、待办等写入 `03-信息记录/YYYY-MM-DD.md`，并在 `03-信息记录/索引.md` 留下简短的检索线索。原 `04-素材库/` 已归入这些日期文件；原 `05-信息记录/` 已改名为 `05-主题资料/`。

具体写入、查询及 Get 笔记同步规则见 [AGENTS.md](AGENTS.md)；用户资料的简短说明见 [USER.md](USER.md)。本地目录重组没有自动更改 Get 笔记知识库。

可执行能力统一由 `zlx-cli` 提供：在项目根目录运行 `npm link` 后，使用 `zlx-cli --help` 查看命令。Skills 只保存工作流程与参考资料；命令设计见 [cmd/README.md](cmd/README.md)。
