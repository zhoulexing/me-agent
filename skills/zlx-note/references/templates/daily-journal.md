# 按日信息记录模板

目标目录：`03-信息记录/`。文件名：`YYYY-MM-DD.md`（Asia/Shanghai 日期，用户指定日期优先）。

```markdown
# YYYY-MM-DD

## YYYYMMDD-01 条目标题

- 时间：hh:mm（未知可省略）
- 类型：个人想法 / 外部资料 / 事件 / 待办 / 研究线索 / 候选选题
- 标签：标签一、标签二
- 来源：原始链接或说明（没有可省略）

原始内容：……
```

同日下一条使用 `YYYYMMDD-02`，以此递增。记录原话与来源；外部观点不可标成用户判断。写完当天文件后，更新 `03-信息记录/索引.md`，每条只写标题、类型、2～4 个标签和不超过 60 字的摘要。已有旧日期文件格式可保留，新记录追加时使用此格式。
