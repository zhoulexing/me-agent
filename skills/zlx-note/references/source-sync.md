# 来源原文同步

## 当前授权与范围

用户已授权 Get → 本地的单向同步，并将展示格式收窄为来源元数据与 Get 正文；不执行旧的每日摘要与 AI 选题逻辑。定时运行时间以现有自动化配置为准，时区为 Asia/Shanghai；没有新增、修改或待迁移格式时不改信息记录。当前配置从 2026-10-07 开始，不回补更早的历史笔记。后续添加来源需要实现对应平台读取适配并明确授权范围。

运行前读取根目录 `AGENTS.md`，然后从固定项目根目录执行：

```bash
node cmd/cli.js record sync --source all
```

预览使用 `--dry-run`。预览会读取来源列表和详情，但不会写入信息记录、保存来源快照或推进同步进度。

## 内容与存放

- `03-信息记录/YYYY-MM-DD.md`：日期按来源创建时间换算为 Asia/Shanghai。标题为 `## YYYYMMDD-序号 原标题`；仅展示同步来源、原始 ID、源笔记类型、源字段 source、源字段 entry_type、源创建时间、源更新时间、源版本、源标签、源知识库，以及存在时的源网页链接（Markdown 链接）。其后只展示 `### Get 正文`，仅取 `content`，非空字符串逐字符保留，包括首尾空白、错字、Markdown 与字面量 `\n`。不展示引用内容、录音转写、网页摘要/原文、附件清单或原始响应链接；正文为空时不使用其他字段补写。
- `03-信息记录/索引.md`：每条来源记录一个链接；正文开头去除 Markdown 排版标记后，截取不超过 60 字作为检索摘录。源标签为空时使用明确标注的系统索引标签，不补造源标签。
- `outputs/信息同步/getnote/<原始ID>/<版本指纹>/`：完整详情响应 `raw.json` 与 `manifest.json`，仅作内部溯源与版本存档，不在日期记录中展示。历史响应与附件存档保留，不因展示格式迁移而覆盖或删除。
- `.zlx-cli/source-sync/`：进度、锁和事务暂存。此目录是运行数据，不能当作原始资料档案。

停止下载图片、音频、PDF、其他文件和正文 Markdown 图片；正文中的原链接原样保留，不重新抓取网页。缺失的源字段不能补写。来源已有的 AI 整理稿仍是来源内容，不当作用户已确认观点。

## 增量与更新

每次完整翻页，验证列表条数与来源总数一致；原始 ID 始终按字符串处理。以来源、凭证身份与原始 ID 管理进度，标题相同不合并。日期范围内的新增与修改都可补拉，因此漏跑后下次执行可以补齐，运行之后产生的内容下一次写回原创建日期。

近期三天的记录还会重新取得详情，以接收平台延后生成的正文。只在模板展示字段变化时更新日期记录；未展示的网页原文、转写、引用、附件及其 URL 签名变化不触发改写或额外版本存档。保存的原始响应仍保留当时完整签名。较早记录依据完整列表的内容和元数据指纹决定是否读取详情。展示版本升级时，已有记录也会重新取得详情并迁移一次，之后重复执行不重复写入；格式迁移同样遵守本地冲突保护。账号凭证发生变化时停止，先核对身份再处理进度，不能混用不同账号。

更新只替换自己的 `SOURCE_SYNC` 来源区块，保留旧原始版本、手写事项和区块外的备注。来源删除不联动删除本地历史。手动修改自动来源区块或来源索引区块后，后续来源更新会停下并报告冲突；将个人备注放在自动区块外更便于持续同步。

## 失败与核验

列表与详情 API 请求至少间隔 1.2 秒。网络或详情失败会重试一次，仍失败则返回失败，不将其写成“没有笔记”。限流按接口或 HTTP Retry-After 指定时间重试，未指定时等待 10 秒；要求等待超过 60 秒、日配额或月配额耗尽、鉴权失败时停止本次。所有所需详情取得后，才准备本地写入；提交前逐字符验证 `content`，并检查本地文件未发生变化。日期记录、索引和来源快照核验成功后，最后提交进度。

多文件写入发生中断时保留 `pending.json`，下一次正常执行先恢复，再读取来源。恢复遇到本地修改则停止，保留双方内容；不要自行删除 pending、状态或锁来绕过冲突。运行锁会自动识别并清理已退出进程留下的锁。

最终根据 CLI 返回的 `status` 和 `results` 报告结果：

- `synced`：简要报告新增、更新数量和日期文件路径；`recovered` 为 true 表示已恢复中断事务。
- `skipped`：没有新增或修改，保持安静，不额外创建或修改记录。
- 非零退出：报告实际失败或冲突，不声称成功，不展示密钥、原始响应、私密全文或附件签名。

定时任务只调用此命令，不能再生成原任务的摘要和视频选题。任务需要本机开机、桌面应用运行且项目可访问。
