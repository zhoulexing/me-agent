主题：大模型推理性能指标
类型：技术概念
标签：LLM、模型推理、性能指标

概念：

1. **TTFT（Time to First Token）**：从发起请求到收到第一个输出 Token 的耗时。
2. **TPOT（Time per Output Token）**：首个 Token 输出后，平均生成一个新 Token 所需的时间。
3. **E2E Latency（端到端延迟）**：从发起请求到完整响应生成结束的总耗时。
4. **TPS（Tokens Per Second）**：模型在持续生成阶段每秒输出的 Token 数量。

指标关系：

- TPOT 越低，持续生成越快。
- TPS 越高，持续生成越快。
- 近似关系：`TPS ≈ 1 / TPOT`，其中 TPOT 需以秒为单位。
- E2E Latency 同时受到 TTFT、输出长度和持续生成速度影响。

备注：TTFT 主要反映请求排队、Prompt 处理和首 Token 生成速度；TPOT、TPS 主要反映模型进入解码阶段后的生成速度。
