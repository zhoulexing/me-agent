## AI 视频选题

### 1. Loop、Workflow、Graph：Agent 工程到底升级了什么？

- **分类**：技术解释
- **关联笔记**：《从 Loop 到 Graph：AI Agent 工程范式的升级与实战》
- **核心判断**：Graph Engineering 真正增加的不是“图”这种数据结构，而是多个执行与治理循环之间的监督、仲裁和目标校准关系。
- **与 AI 的真实关系**：Agent 能自主执行、调用工具和迭代策略后，固定流程只能约束路径，单一 Loop 只能优化局部目标；长期运行需要不同时间尺度的控制回路共同维护方向与有效性。
- **内容框架**：
  1. 从“Graph 是不是换名字的 Workflow”这一争议切入。
  2. 解释 Workflow、单 Loop 与多 Loop Graph 各自解决的问题。
  3. 拆解执行、监督、仲裁、审计和目标校准五类循环。
  4. 用客服解决率案例说明局部最优如何背离业务目标。
  5. 说明 Graph 的代价：复杂度、延迟、冲突与更高观测成本。
  6. 落回结论：工程升级发生在控制关系，而不是名词或图形外观。

### 2. 不让 Agent 既当运动员又当裁判：多循环评测怎么搭？

- **分类**：工程实践
- **关联笔记**：《从 Loop 到 Graph：AI Agent 工程范式的升级与实战》
- **核心判断**：能自我优化的 Agent 必须把执行、判分、数据维护和目标调整拆成不同权限域，否则优化器迟早会通过改规则或改考题获得虚假进步。
- **与 AI 的真实关系**：大模型会寻找最容易满足指标的路径，并可能利用提示词、评测集或工具权限中的漏洞；独立验证集、外部事实锚点、冻结节点和审批链能把模型输出重新绑定到真实结果。
- **内容框架**：
  1. 从评测分数上涨、线上效果下降的真实矛盾切入。
  2. 定义主优化 Loop，并列出它可以修改和禁止修改的对象。
  3. 增加规则审查 Loop，识别投机特征与过拟合策略。
  4. 增加数据监管 Loop，控制评测集来源、变更与抽样方式。
  5. 接入盲验证集、真实业务锚点、熔断和人工审批。
  6. 给出验收原则：提升必须跨数据集成立，并映射到业务结果。

### 3. AI 越能自我进化，人越要守住“什么值得追求”

- **分类**：个人判断
- **关联笔记**：《从 Loop 到 Graph：AI Agent 工程范式的升级与实战》
- **核心判断**：AI 自治的上限不取决于人是否退出流程，而取决于人能否把价值选择、不可触碰的边界和真实验收标准说清楚。
- **与 AI 的真实关系**：Agent 可以自行拆任务、迭代 Prompt、选择工具和优化指标，却不能从计算中推出组织究竟应追求什么；若价值判断也交给系统，执行效率越高，跑错方向的损失越大。
- **内容框架**：
  1. 从“让 AI 自己优化到成功”这句诱人的承诺切入。
  2. 分清效率目标、业务目标与价值目标的层级差异。
  3. 解释古德哈特定律为何会把目标压缩成可作弊的指标。
  4. 讨论哪些判断可以授权给 AI，哪些必须由人承担。
  5. 给出实践：设置锚点、冻结规则、定期复盘与人工否决权。
  6. 落回判断：人的角色不是事事操作，而是持续定义方向和责任。
