### 🤖 DS Bot 是什么，谁做的？

DS Bot 是**社区开发者**打造的 DSH 插件，**非官方项目**。
- **核心定位**：基于 **DeepSeek Harness（DSH）** 开发，把 DSH 变成一组**持久化 Bot**
- **形象比喻**：有着 grokbot 的皮，长着 DSH 的心
- **版本信息**：v0.1 preview，基于 DSH 0.2.1-alpha.1，采用 **Apache 2.0** 协议
- **项目地址**：https://github.com/FeiZhuLulu/DeepSeek-Bot

### ⚙️ 核心能力有哪些？

用自己的 API Key 创建专属 Bot，**每个 Bot 独立上下文和记忆**。
- **多场景支持**：聊天、写代码、干活都行
- **单窗口持续工作**：不用反复交代背景
- **模型可独立配置**：每个 Bot 可单独选模型，建议长期固定一个
- **Bot 详情页**：可查看模型、记忆条目、用量（token、缓存命中率）

### 👔 主 Bot Chief 负责什么？

Chief 是预设的**总管 Bot**，帮你搭建和管理 Bot 团队。
- **核心权限**：管理其他 Bot、建群聊、分配任务
- **使用流程**：直接告诉 Chief 需求 → 它自动创建对应 Bot → 拉群开始协作
- **示例场景**：说"建一个 Writer 写博客、一个 Coder 写代码，再拉个群" → Chief 自动完成全部配置

### 👥 群聊怎么实现多 Bot 协作？

群聊设**管理员机制**，在协作效果和 token 成本间找平衡。
- **默认模式**：只有管理员（通常是 Chief）回复你的消息，由它判断该调用哪些 Bot
- **直接调用**：也可以 **@ 指定 Bot** 让它直接回答
- **用量统计**：在 Settings → Usage 里查看，支持按**时间、Bot、模型**三个维度展示
  - 示例数据：7 天用了 **117K tokens**，缓存命中率 **50%**，输出 **4.62K**，调用 **13 次**

### 📦 怎么安装？

前提是先装好 DSH 并配置至少一个模型，DS Bot 直接复用 DSH 的模型配置。

| 版本 | 安装方式 |
| :--- | :--- |
| DSH Desktop（Win/macOS） | 侧边栏 Plugins → Add plugin → 填 ds-bot → 启用重启 |
| DSH Web（全平台） | 需 Node.js 22.19+ 和 pnpm，用命令行安装 |
- **国内网络建议**：把 Registry 切到**大陆镜像**
- **Web 版命令**：
  ```
  npx @deepseek-ai/dsh@0.2.1-alpha.1 plugin --profile web add ds-bot  
  npx @deepseek-ai/dsh@0.2.1-alpha.1 web
  ```
### 💾 数据存在哪？

所有数据**保存在本地**，卸载插件不会删除。
- **存储位置**：DSH 目录（默认 `~/.dsh`）下的 `bot/` 和 `sessions/` 文件夹

### 🔮 兼容性和未来规划？

大部分 DSH 插件兼容，下一版确定做**浏览器操控**。
- **已测试兼容**：dsh-web-ui-all、dsh-browser、dsh-ads 及多款记忆插件（大部分正常）
- **已知问题**：
  - dsh-web-ui-all 在 macOS 上会导致下次启动失败
  - dsh-ads 是占位包
- **规划中功能**：
  - 浏览器操控（下一版确定做）
  - 电脑操控（还在考虑权限设计）
  - 支持接入本地 agent，直接使用已有的 AI 订阅
- **开发者承诺**：会开源更多开发技巧、方法及思考取舍

### ⚠️ 有什么需要注意的？

这是**社区个人兴趣项目**，距离成熟还有很长距离。
- 非官方推出，DSH 本身也尚处于起步阶段
- 关注公众号回复"进群"可入群讨论

### 📑 直播概览
- **主题**：AI时代的家庭教育新解
- **主讲人**：罗振宇（得到APP创始人）、沈祖芸（教育专家）、李睿（硕图科技创始人）
- **开始时间**：2026-09-30 14:30:00
- **时长**：约1小时21分钟

### 🎯 重点内容
1. **AI是堪比人类用火级别的文明级变量**
- AI并非普通的技术革命，而是能渗透到所有旧事物中重塑可能性的底层变量。
  * 类比人类掌握火之后，从武器升级、陶器冶炼到生理结构全维度改变文明形态。
  * 比尔盖茨的观点佐证：人类总是高估短期2年变化，却低估长期10年的颠覆性影响。
  * 当下所有人都处于同一起跑线，没有任何人能完全说清AI的未来走向。
- 全球所有学校的AI教育起点都只有3岁，老牌名校反而因为存量包袱转型更困难。
  * 起点从2022年底ChatGPT3.0正式上线的时间点算起，至今仅3年多。
  * 所有校长、老师都处于同一起步的"幼稚状态"，过往的教育经验存量反而可能成为转型阻碍。

2. **AI时代家庭教育的核心是挖掘孩子的独特性**
- 学校的制度属性决定了它天然以统一标准分配未来，并非为培养独特性而生。
  * 传统学校通过统一考核、集体教学，批量输出符合社会人才规格的标准化人才。
  * 学校的转型节奏缓慢，AI带来的变化速度远超学校的迭代效率，投入到孩子真实成长的转化效率偏低。
- 家庭是培养孩子独特性的天然场景，完全可以走在学校前面错位发展。
  * 家庭面对的是独一无二的具体孩子，不需要通过排名来定义孩子的价值。
  * 家校协同的核心交集是共同培养孩子应对不确定世界的能力，而非把家庭变成学校的夜间分校。

3. **用AI做真实项目是孩子成长的高效路径**
- 孩子使用AI的核心是建立"伙伴助手"关系，而非把AI当成抄作业的工具。
  * 孩子在实操中会自然发现AI并非万能，需要主动梳理问题、反复和AI沟通校准结果。
  * 过程中孩子会自发理解"客观共情"的意义，不需要生硬的道德说教就能建立同理心。
- 家庭落地AI项目的四个可操作步骤，零门槛就能开展。
  * 第一步从身边的真实小问题入手，不用在意问题大小和收益，比如帮楼下小卖部提升销量。
  * 第二步给孩子充分探索空间，允许他们自主研究3D打印、外包制作等超出课本的技能。
  * 第三步利用AI时代极低的试错成本，哪怕是"让宠物写检讨书"这类看似荒诞的想法也鼓励落地。
  * 第四步一定要让孩子拿着成品找真实用户获取反馈，而非只在家长老师的庇护下获得预设的成功。

4. **AI时代孩子的核心竞争力来自早、真、韧三个维度**
- 早起步：AI抹平了年龄和技术门槛，孩子可以越级打怪，提前参与成年人的项目。
  * 10岁左右的孩子不需要掌握复杂的底层技术，借助AI就能完成完整的产品开发。
  * 当下10后是原生AI原住民，未来在AI相关领域的竞争力远超年长世代。
- 真挑战：让孩子直面真实的甲方反馈和市场评价，拒绝提前安排好的"表演式成功"。
  * 孩子们给跨年演讲做的个性化门票方案被真实甲方直接否决，没有走后门通融。
  * 真实的挫败感远比对孩子刻意的"抗挫折训练"更有价值。
- 强韧性：在真实项目的反复迭代中自然培养抗挫能力，不需要刻意"没苦硬吃"。
  * 孩子拿着自制故事机去游乐场找小朋友测试，收获大量负面反馈后自主复盘优化。
  * 面对毒舌行业专家的质疑、陌生用户的拒绝，都是孩子成长的宝贵养分。

5. **两个面向普通家庭的AI时代家庭教育实操建议**
- 第一个"馊主意"：家长先放下焦虑，对人性的弹性和创造力保有基本信心。
  * 过往几代人经历了从农耕时代到智能时代的多次技术跃迁，落后的教育体系也没有限制住个体发展。
  * 很多家长的教育焦虑本质是把自己童年的成长阴影投射到孩子身上，并非孩子真的面临绝境。
  * 双胞胎在几乎相同的成长环境下依然会长成完全不同的个体，教育的作用其实非常有限。
- 第二个"馊主意"：帮孩子从12岁开始搭建持续结构化的个人成长数据库。
  * AI的能力边界受限于训练数据，活人生产的独特感知数据是AI永远无法替代的核心价值。
  * 12岁到22岁大学毕业，每天记录300字的思考和感知，10年就能积累百万字的个人成长作品集。
  * 未来社会不需要用毕业证这种低信息量标签来定义人，AI可以直接通过完整的成长数据库全面了解一个人。

**核心内容**：沈祖芸通过学校和家庭的真实案例，拆解AI时代学校转型的局限性，点明家庭才是培养孩子独特性的最佳场景。

  * 传统音乐会模式下，孩子只需要练好指定曲目上台表演，所有策划、受众调研、应急处理都由老师完成。
  * 创新模式下，孩子需要自主调研流动的餐厅观众喜好、选择适配曲目、组织团队、处理突发状况，全程在真实场景中解决问题。
  * 后者能快速锻炼孩子的受众感知、问题解决、团队协作等AI无法替代的综合能力。
- 延伸到家庭日常场景的能力培养改造，把普通指令升级为能力生长任务。
  * 普通指令是让孩子帮奶奶拨通视频电话，只是完成一个简单操作。
  * 升级任务是让奶奶下次能独立拨通视频电话，孩子需要主动观察奶奶的操作卡点，设计适配老人的指引方案，锻炼共情和沟通能力。
  * 这类日常场景的改造，完全不需要额外报班花钱，就能在生活中自然培养孩子的核心能力。

  * 把亲子关系当成家庭教育最核心的资源：借助AI节省出来的时间，全部投入到构建良好亲子关系上，这是培养孩子独特性的基础。

  * 第二是自然生成共情能力：孩子们做"AI安慰自己"项目时，自发否决了"AI无条件站在我这边"的初始方案，意识到客观分析比无底线偏袒更能平复情绪。
  * 第三是跳出"一键生成"的懒人思维：孩子会主动去调研产品为什么好玩、用户为什么需要，不会把自己的脑子完全外包给AI。

  * 早：10岁左右的孩子借助AI就能越级打怪，参与成年人的黑客松比赛，不需要先花几年时间学习复杂的底层技术。

**核心内容**：罗振宇结合自己作为双胞胎父亲的亲身实践，给出两个接地气的家庭教育建议，消解家长焦虑，点明AI时代人的独特数据价值。
