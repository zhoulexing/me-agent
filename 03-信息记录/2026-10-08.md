### 🔍 为什么需要 dsh-context？

DSH 长任务**上下文占用明细不透明**，出问题只能事后翻记录。
- **痛点**：界面只显示总占用，系统提示、工具 schema、工具返回、注入内容各占多少看不到
- **定位**：DeepSeek Harness 的**开源插件**，把上下文组成、变化、压缩/剪枝过程全部可视化

### 📍 有哪几个查看入口？

一共 **4 个入口**，适用场景各不同。

| 入口 | 适用场景 |
| :--- | :--- |
| Context 标签页 | 查看当前单会话详情 |
| Context Insights 页面 | 跨会话看一段时间总用量 |
| 右侧栏 Context 面板 | （原文未单独说明） |
| `/context` 命令 | 聊天中临时弹窗查看当前组成 |

### 📊 跨会话用量能看到什么？

**Context Insights** 汇总所有会话的用量与成本。
- **核心指标**：会话数、计费 token、估算费用、**缓存命中率**、工具调用次数、活跃时长
- **可视化**：最近 7 天用量柱状图 + 近几周活动热力图
- **会话卡片**：每个会话带上下文组成环、token 数、轮次、估算费用
  - 支持按最近时间 / token 量 / 上下文大小排序
  - 支持按工作区分组
- **费用说明**：按 models.dev 目录价估算，已计入 DeepSeek 峰谷价，**仅作参考**

### 📑 单个会话的 Context 页面有什么？

单会话数据**集中在一页**，不用来回切换。
- **顶部统计**：轮次、步数、工具调用次数、缓存命中率、token 去向占比、时间分配
- **数据一致性**：占用率与组成和 DSH 官方 token meter 用**同一组投影数据**，与输入框旁的上下文环数字一致
- **下方模块**：当前窗口、上下文趋势、Context Browser、事件、文件活动、Agent 网络

### 📏 当前窗口组成怎么看？

用**多色堆叠条**展示 6 类内容的占比。
- **6 类组成**：系统提示、工具 schema、用户消息、注入内容、助手回复、工具结果
- **剩余空间**：用斜纹标识
- **实用提示**：上下文不够用时，**工具定义和工具结果**通常占大头，不一定是用户输入过多
- **精度说明**：分类数字为 DSH 固定密度启发式估算，非精确测量；钉住某一步后，provider 上报的实际 prompt / output / cache 数字更可靠

### 📈 上下文变化趋势怎么看？

**Context Trend** 按每次模型请求画堆叠条，粒度更细。
- **粒度切换**：支持 Step（步）或 Turn（轮）两种粒度
- **查看模式**：Total（总量） / Delta（增量）
  - Delta 模式：增长堆在基线上方，压缩往下掉，长会话压缩次数一目了然
- **Step 摘要**：图下方显示用户输入、新增上下文内容、模型回复/工具调用
- **压缩标记**：压缩和剪枝标在对应柱子上，可看到回收 token 数

### 🗂️ Context Browser 能查到多细？

可展开查看**每次请求的完整组成内容**。
- **可展开项**：
  - 系统提示 → 看原文
  - 工具 → 看 JSON schema
  - 消息 → 看正文
  - 工具结果 → 看参数、状态、返回值
  - 助手回复 → 可按 Thinking / Tools / Answer 筛选
  - 图片 → 卡片展示缩略图、尺寸、存储大小、DeepSeek 图像 token 估算
- **工具来源标记**：标注官方 `tool-*` 包、`dsh-*` 能力包、MCP server、插件注册工具
- **轮次 diff**：与上一轮对比，增减 token 数用徽标标出
- **注意**：压缩前步骤从被移除消息归档重建，界面标"近似"，仅作参考

### 📁 文件活动和 Agent 网络有什么用？

分别展示**文件操作轨迹**和**多 Agent 关系**。
- **File Activity**：
  - 分类：读 / 写 / 搜索路径 / 处理图片
  - 写操作估算新增/删除行数，点开可看完整操作记录，跳回对应工具结果
- **Agent Network**：
  - 展示主 Agent、父级 Agent、所有子 Agent 的关系
  - 每个节点对应一个会话，环大小按窗口占用缩放
  - 悬停看 token、请求数、费用、活跃时间，点击跳转对应会话 Context 页
  - 适合多 Agent 会话快速排查各 Agent 占用情况

### 🛠️ 怎么安装？

两种方式，**无需手动构建和额外重启**。
- **界面安装**：DSH Web/桌面端 → Add plugin → 搜索 `dsh-context` → Install
- **命令行安装**：
  ```
  dsh plugin --profile web add dsh-context
  ```
- **更新命令**：
  ```
  dsh plugin --profile web update dsh-context@latest
  ```
- **启动**：装完用 `dsh web` 启动 Web UI

### ⚠️ 兼容性和注意事项？

有明确的版本要求，且插件**只观测不干预**。
- **兼容版本**：
  - DSH：`@deepseek-ai/dsh` 0.1.5-rc.1、0.1.7-rc.2、0.2.0-rc.2
  - Node：`^22.19.0` 或 `>=24.0.0`
  - 旧版本建议先升级 DSH
- **能力边界**：
  - ✅ 观测、定位、回看上下文
  - ❌ 不会主动删上下文
  - ❌ 不会替你决定何时压缩
  - 省 token 仍需从工具数量、提示词、注入内容、任务拆分入手
- **安全提醒**：插件是本机运行的第三方代码，安装前建议检查源码、依赖、仓库活跃度

### 🎯 适合哪些场景？

**长会话、多工具、多 Agent** 场景价值最大。
- 偶尔短聊 → 差别不大
- 长会话 + 多工具 + 多插件 + 多 Agent → 信息增益明显
- 定位：**排查工具**，不改模型、不省 token，只把上下文明细摊开供判断
