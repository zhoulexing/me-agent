## 研究目标

研究 AI Agent 在长链路、多工具和高并发业务场景中，如何做到：

- 过程不跑偏
- 中间状态不丢失
- 失败可恢复或回滚
- 最终结果可验证
- 高风险操作可控制
- 整条执行链路可观测、可复盘

## 第一层：规划与状态管理

### 课题 1：Agent 规划模式的场景化选型

研究 ReAct、Plan-and-Execute、Plan-and-Solve、Tree of Thoughts 等模式在简单查询、长链路推理、多工具协同和复杂决策场景中的适用边界，对比任务完成率、执行步数、成本、耗时和错误传播情况，最终形成规划模式选型矩阵。

备注：视频自动转写中的“Plan and Soft”可能存在识别错误，后续需要回看画面或其他资料确认具体术语。

### 课题 2：长任务的动态拆解机制

研究如何根据业务复杂度动态决定任务粒度，识别任务拆得过大、过碎、循环依赖、步骤遗漏和重复执行等问题。目标产出任务 DAG、动态拆解规则和拆解结果校验器。

### 课题 3：计划与执行的一致性校验

研究如何在每一步执行前后校验原始目标、当前计划、工具调用和实际结果，识别“工具调用成功但业务目标已经跑偏”的情况。目标产出 Goal—Plan—Action—Result 四层一致性校验模型。

### 课题 4：上下文压缩与关键状态保真

研究长任务上下文压缩时，事实、约束、计划、工具结果、业务状态和未完成步骤应如何分层保存，明确可丢弃信息与不可丢弃信息，建立压缩前后的状态一致性测试。

### 课题 5：步骤缓存、结果缓存与状态复用

研究哪些步骤可以缓存，哪些非幂等或高风险操作不能复用，以及缓存键、版本、权限隔离和失效机制如何设计，避免旧状态命中和跨任务污染。

## 第二层：执行量化与容错机制

### 课题 6：Agent 长任务可靠性指标体系

建立端到端任务完成率、最终结果正确率、中间状态一致率、首次执行成功率、平均执行步数、重复调用率、人工接管率、回滚成功率、任务成本和 P95 耗时等指标，明确技术成功与业务成功的区别。

### 课题 7：工具调用的幂等性与错序防护

研究重复调用、并发调用、网络超时和工具错序情况下，如何避免重复扣款、重复发货、重复建单等业务问题。目标产出工具风险分级、幂等键设计、执行凭证和前后置条件规范。

### 课题 8：失败补偿——重试、回溯还是回滚

研究不同错误场景应该选择原地重试、断点恢复、补偿事务还是完整回滚，重点处理跨系统调用和不可逆操作。目标产出 Retry、Resume、Compensate、Rollback 决策矩阵。

### 课题 9：有限状态机与检查点机制

研究如何将自然语言计划映射成确定性的任务状态机，如何设置检查点，以及 Agent 或进程重启后如何从真实业务状态恢复。目标产出状态机、Checkpoint 数据结构和状态迁移校验规则。

### 课题 10：重规划的触发条件与成本控制

研究工具连续失败、实际状态与预期状态不一致、依赖失效、预算不足和执行步数超限等情况下，何时触发重规划、回退到哪一级，以及如何避免“规划—失败—再规划”的死循环。

## 第三层：生产架构与治理体系

### 课题 11：工具与任务的准入、分级和审批

研究如何按读取、可逆修改、不可逆修改、交易和删除等风险对工具与任务进行分级，明确哪些操作可以自主执行、哪些必须人工确认，最终形成准入规范、风险矩阵和上线红线。

### 课题 12：并发、预算与系统性雪崩防护

研究单任务最大执行步数、模型调用次数、成本预算和单实例并发数如何设置，以及下游变慢时如何通过队列、限流、背压、超时、熔断和降级避免批量任务雪崩。

### 课题 13：全链路可观测性与事故复盘

研究如何使用 Task ID、Plan Version、Step ID、Tool Call ID 和状态快照还原完整执行时间线，定位模型、规划、工具、状态或调度问题，并将事故结论回灌为 Prompt、Policy、代码约束和测试用例。

建议链路结构：

```text
Task ID
  -> Plan Version
    -> Step ID
      -> Tool Call ID
        -> Input / Output
          -> State Before / After
            -> Validation Decision
              -> Retry / Rollback / Human Approval
```

## 建议研究顺序

### 第一阶段：建立最小可靠性闭环

1. 可靠性指标体系
2. 计划与执行一致性校验
3. 工具幂等性与错序防护
4. 状态机与检查点
5. 失败恢复策略

### 第二阶段：提升长任务能力

1. 动态任务拆解
2. 上下文压缩与状态保真
3. 重规划机制
4. 缓存与状态复用
5. 规划模式选型

### 第三阶段：推进生产落地

1. 工具和任务准入与审批
2. 并发与雪崩防护
3. 全链路可观测性与事故复盘

## 当前判断

视频将规划模式放在第一层，但实际开展研究时，建议先定义可靠性指标和状态模型。否则无法客观判断一种规划模式是真的更可靠，还是仅仅“看起来能够运行”。
